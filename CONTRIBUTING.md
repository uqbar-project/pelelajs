# Contributing to PelelaJS

Thanks for your interest in PelelaJS! This is a didactic framework, and we
especially welcome first-time contributors: students, teachers, and anyone
curious about how a frontend framework works under the hood.

This file is the short version. Setup instructions and project conventions
live in the [Developer Documentation](./docs/DEVELOPMENT.md).

## Getting started

- [Initial setup](./docs/DEVELOPMENT.md#initial-setup): clone the repository,
  install dependencies, and build the framework.

- [Skills by area](./docs/DEVELOPMENT.md#skills-by-area): find the area that
  best matches what you already know.

- [Recommended readings](./docs/DEVELOPMENT.md#recommended-readings): papers
  and guides on MVC, MVVM, reactivity, TypeScript, and Vite.

## How we work

Read [How We Work](./docs/DEVELOPMENT.md#how-we-work) before opening a pull
request. It covers branches, commit messages, and the checks CI runs.

Code follows the [working rules](./docs/DEVELOPMENT.md#working-rules) and the
[architecture conventions](./docs/DEVELOPMENT.md#architecture-conventions).
If you use an AI assistant, point it to [AGENTS.md](./AGENTS.md) and the
[Graphify setup](./README.md#using-ai-assistants).

## Community

- **Discord:** [https://discord.gg/kym9qqGyx](https://discord.gg/kym9qqGyx) is
  the place to ask questions, propose ideas, and meet other contributors.

- **Code of Conduct:** all participation is covered by our
  [Code of Conduct](./CODE_OF_CONDUCT.md). Reports go by direct message to a
  maintainer with moderation duties in Discord.

- **Security issues:** do not open a public issue. Report vulnerabilities
  privately through
  [GitHub Security Advisories](https://github.com/uqbar-project/pelelajs/security/advisories/new).
